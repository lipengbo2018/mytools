# MyTools 工具站导航

MyTools 是一个单页个人工具站导航，用来集中收藏和管理日常使用的网站与工具入口。

## 功能特性

- 在首页查看全部已配置工具站。
- 按分类筛选工具站，支持“未分类”视图。
- 通过关键词模糊搜索工具站。
- 收藏常用工具，并在“收藏”菜单集中查看。
- 新增、编辑、删除工具站。
- 新增、编辑、删除分类。
- 导入和导出 JSON 配置备份。
- 当浏览器本地没有配置时，从 `mytools.default.json` 加载默认配置。

## 文件说明

- `mytools.html`：独立运行的工具站导航页面。
- `mytools.default.json`：页面首次启动时使用的默认配置。
- `mytools_readme.md`：详细需求文档。

## 使用方式

直接用浏览器打开 `mytools.html`，或使用任意静态文件服务器托管当前目录。

页面会把用户修改保存到浏览器 `localStorage`。如果需要更新仓库里的默认数据，可以在页面中点击“导出默认配置”，再用导出的文件覆盖 `mytools.default.json`。
